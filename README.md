# NetMusicNeedKuGou
本模组对[NetMusic](https://www.mcmod.cn/class/4935.html)添加了酷狗概念版渠道！！！

## 功能

- 在线搜索酷狗音乐库
- 扫码登录酷狗账号
- 多音质选择
- CD 刻录 + 歌词显示
- 支持多人联机

## ⚠️ 注意

- VIP 歌曲需要登录且部分歌曲刻录需要拥有 VIP 权限
- 本 mod 处于初步测试阶段

---

## 配置说明

在模组列表搜索"NetMusicNeedKuGou"后点击配置按钮。

### 第一步 — 登录
用酷狗概念版App扫码登录。首次使用请先注册账号。

![登录界面](images/screenshot1.png)

### 第二步 — 音乐源与音质
选择音乐源、管理 VIP Cookie（登录后自动填入）、选择音质。

![音乐源设置](images/screenshot2.png)

### 第三步 — VIP 设置
配置 VIP 相关选项和歌词显示偏好。

![VIP设置](images/screenshot3.png)

### 第四步 — 歌词显示
配置歌词显示样式。罗马音显示可选但一般不推荐开启。

![歌词显示](images/screenshot4.png)

---

## 刻录流程

1. 打开唱片刻录机
2. 搜索想要的歌曲
3. 选择歌曲并提供唱片
4. 点击"制作唱片"

![刻录机](images/screenshot5.png)

![搜索](images/screenshot6.png)

![制作唱片](images/screenshot7.png)

> 界面看起来像 [看你的QQ](https://www.mcmod.cn/class/24789.html)因为我们借鉴了它

## 多人联机

刻录的唱片在多人联机中跟单机一样使用——其他玩家也能听到音乐。

## 限制说明

- 部分歌曲可能因版权无法获取对应URL
- 首次刻录和播放需要稳定的网络连接
